# Support

OSImageDeploy is supplied free of charge without a support entitlement or
service-level commitment.

For reproducible product defects and improvement suggestions, use GitHub
Issues. For private security reports, follow [SECURITY.md](SECURITY.md). For
licensing, commercial, or permission enquiries, use the contact route at
[x9000.com](https://x9000.com).

Do not attach Windows installation images, OEM driver packages, product keys,
private certificates, secrets, personal data, or unredacted stable hardware
identifiers to an issue.
