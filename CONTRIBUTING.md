# Suggestions and project participation

OSImageDeploy is a proprietary, source-visible showcase developed and
maintained by x9000.com Consulting Services Limited. The source is published so
people can understand the design, evaluate the product, report problems, and
suggest improvements. It is not operated as a community-developed project.

## Suggestions and bug reports

Feature ideas, usability feedback, reproducible bug reports, and documentation
corrections are welcome through GitHub Issues. Before opening an issue, check
whether an existing issue already covers it.

Useful reports identify:

- the installed OSImageDeploy version;
- the Windows and ADK/WinPE versions;
- whether the result came from an installed product or a development build;
- the exact stage and visible error;
- whether the test was automated, VMware-based, or performed on physical
  hardware; and
- diagnostic output with secrets, personal data, stable hardware identifiers,
  Windows images, and OEM packages removed.

Never post a vulnerability publicly. Follow [SECURITY.md](SECURITY.md).

## Pull requests and code contributions

Unsolicited pull requests and source-code contributions are not accepted. The
maintainer may use an issue suggestion as inspiration and implement it within
the project's own development process. Please do not invest time preparing a
patch unless x9000.com Consulting Services Limited has agreed to it in writing
first.
